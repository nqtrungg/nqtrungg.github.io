Banking Credit Risk
Dashboard.

Power BI · SQL · Python · Machine Learning

The problem

How can a credit team monitor portfolio health, identify high-risk segments and evaluate model performance from millions of loan records?

The raw lending data was too large and granular for manual review. Origination, borrower risk, delinquency, credit loss and model quality needed to be connected in one analytical flow.

The repository contains the reproducible training, validation and test workflow, including preprocessing, baseline comparison, threshold analysis and model evaluation. Exact model scores are kept with the project outputs so the portfolio does not present unverified values.

Key insights

Risk rises sharply across credit grades.

Default dispersion supports grade-aware underwriting, pricing and exposure limits.

Portfolio size alone does not describe portfolio quality.

Funded amount, default probability, interest return and net credit loss must be evaluated together.

Purpose and borrower profile reveal concentrated risk.

Segment-level analysis helps focus underwriting review and collection priorities.
