01 / The problem

Start with the
decision.

Credit risk analysts need a clear view of portfolio health, borrower risk and financial performance, but large-scale loan data is difficult to analyze manually. The project focuses on organizing these signals into a single decision-oriented analytical experience.

02 / The solution

Build the
workflow.

The solution combines an analytics workflow with a six-page Power BI dashboard covering portfolio overview, credit quality, delinquency analysis, financial performance, customer insights and machine learning model monitoring.

  • Portfolio health and credit quality monitoring
  • Delinquency and borrower-risk analysis
  • Financial performance views
  • Customer segmentation and insights
  • Machine learning model monitoring
